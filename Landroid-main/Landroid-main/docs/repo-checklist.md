- Keep repository private for entire hackathon lifecycle.
- Do not commit Birdscale datasets to source control.

- Run `python -m pytest` in `backend/` before every demo.
- Rehearse `docs/demo-script.md` end-to-end with timer.
- Keep `docs/evidence/` updated with latest screenshots/videos.
